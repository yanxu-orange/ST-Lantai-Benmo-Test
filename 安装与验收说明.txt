本次变化：
- 主题、普通设置、功能开关、时间配置、工坊条目模板：采用当前状态后交给酒馆保存，取消每次服务器回读和宿主完成等待。

- 记忆正文、总结成果、收集正文、人工修改的追踪结果仍保留保存确认；API 配置与密钥的前后检查保留。
- 工坊跨全局／当前聊天移动先确认目的地，再移除源条目。聊天归属、防重复和迟到结果保护保留。

已接受的取舍：普通“已保存”表示当前配置已采用并交给宿主，不代表逐次落盘验证；后台保存失败插件可能无法立即知道，普通落盘顺序采用宿主语义。记忆成果与 API 的受保护写入仍会等待先前普通保存，防止旧快照迟到覆盖。

建议实机核对：
1. 两主题切换与普通设置、功能开关连续操作，页面不再等回读完成。
2. 工坊编辑普通条目保存返回列表；连续开关、删除和切页，最终界面显示最新选择。
3. 编辑校验失败保留输入；全局与当前聊天互移后条目不丢失，刷新后核对归属。
4. 保存期间关闭／切聊，不出现旧页面回弹或跨聊天改动；保护移动期间新输入不被旧结果覆盖。
5. 记忆／收集结果编辑和 API 保存仍走保护路径；正常刷新后核对常用配置持久性。
