兰台正文补充 BM25 隔离试用
版本：0.1.0-trial.bm25.20261018.1
正式源码基线：7ea08ad44abfac57c7136e75bb10211a91a85aa4

这是什么
这是同一个兰台插件的替换试用包，不是第二个可并行开启的插件。已发布到独立试用分支 trial/bm25-supplement-20261018；未合并、未修改正式 main。正文补充和加强提醒都默认关闭，无需提供 API 密钥。

安装前
1. 关闭 SillyTavern，备份现有兰台插件目录、SillyTavern 全局设置和聊天资料。备份放在 extensions 之外，避免宿主扫描出第二份插件。
2. 记下原插件所在目录与当前版本。若不确定怎样备份与替换，先不要安装。
3. 不删除、不重置原聊天或记忆，不同时启用两份兰台。

安装
1. 将安装包解压到临时目录，确认顶层有 manifest.json 和 dist/。
2. 在停用宿主时，用这两项替换原兰台插件目录中的同名项。保留原目录名，不新建一个并行插件目录。
3. 重新启动 SillyTavern，确认兰台显示试用版本 0.1.0-trial.bm25.20261018.1。
4. 先保持“正文补充（试用）”关闭，比较原召回。然后进入兰台召回设置，打开它。默认独立完整卡上限为 500 Token；填 0 不补入。
5. “加强历史记忆提醒”也默认关闭，仅本次确实补入正文卡时生效。原版已有历史记忆引导，没有再叠一份独立提示词。

观察
- 正式召回先按你现有的最近语境、常驻、时间池、条数和预算产生完整结果，不重置为实验用的四条／零历史。
- BM25 只看清洗后的当前输入与有效触发记忆正文。最多额外一条，若第一名已选就不补，也不改找第二名；超预算不截断，不挤掉原卡。
- 监控与测试能看到额外补入什么、没有补入的原因与成本。分数是词面匹配信号，不是有用性或置信度。
- 额外预算计算整张卡的日期、标题与正文，不含固定包裹文本和可选提醒；不代表整个提示词或 API 价格。宿主计数器缺失时标明估算；计数失败只取消补充。
- 现有设置是全局召回设置，换聊天后仍沿用开关；检索资料和实际结果按当前聊天／版本重算，不共用其他聊天的记忆。

停止与回退
- 发现无关旧事干扰、旧关系误导、没有感知收益或等待成本不值得时，先关闭正文补充，不必删除记忆。
- 完整回退时关闭宿主，恢复原插件目录，并同时恢复试用前的全局设置备份。旧版不认识新增设置字段，不能只换回代码而保留试用配置。
- 如果试用期间新增了重要聊天／记忆，先单独备份这些新成果再决定恢复哪些聊天备份，不要直接覆盖丢失它们。

已知限制
- 这次以 main 为基线，没有合并独立时间解析修复分支 15ab4b9a。保留原版时间行为；不能把离线修复回放当作本版保证。
- 仅完成离线工程验证，不证明 Gemini／Claude 的续写质量提高；未调用真实 API、读取真实密钥或改动用户数据。
- 云端浏览器检查被运行环境阻断，手机宽度视觉检查、真实 SillyTavern／Termux 与手机性能尚未验证。
- Node 合成性能不等于手机表现。1000 条合成记忆、2997 个不同保护词时，开启后的中位约 1.21 秒、最慢约 1.87 秒，正式发送路径可能同步等待。建议先用现有小库试用，感觉明显卡顿就关闭；未设静默库大小限制，也未改分词器，详见验证说明。

分支安装入口
仓库：https://github.com/yanxu-orange/ST-Lantai-Benmo-Test.git
分支：trial/bm25-supplement-20261018
这是安装树，已包含 dist，无须自行构建。不要使用私有源码仓库安装。

尚未安装兰台：在酒馆“安装扩展”中填写上述仓库地址，并在单独的分支栏填写上述完整分支名。分支栏留空会安装 main 正式版，不会安装本试用版；不要把 /tree/ 页面地址填进仓库栏。
已有兰台（优先用界面）：先备份插件、全局设置与聊天，停止生成／总结；打开扩展管理／详情，在兰台右侧点击“切换分支”（分叉图标），选择 origin/trial/bm25-supplement-20261018（已存在本地分支时可能不带 origin/），确认 Switch 后刷新，核对版本 0.1.0-trial.bm25.20261018.1。当前官方版本中该按钮仅管理员可见；若找不到按钮或分支，不要拼接 #branch，不要删数据或重复安装，可先确认酒馆版本／权限。

备用原目录 Git 路径：普通“更新”仍跟随当前分支，不能假定已经切到试用版。先完成备份，停止宿主，在原插件目录检查 git remote -v 与 git status，确认 origin 是上述安装仓库且没有未保存修改，再执行 git fetch origin refs/heads/trial/bm25-supplement-20261018:refs/remotes/origin/trial/bm25-supplement-20261018 和 git switch --track origin/trial/bm25-supplement-20261018。显式抓取避免旧安装只追踪 main 时看不到试用分支。如果本地已经有同名分支，使用 git switch trial/bm25-supplement-20261018。不要强制切换、丢弃本地修改或另外安装一份。无 Git 的 ZIP 安装按上方替换方式操作。
回退 main 前仍须恢复试用前全局设置；仅切回 main 不能让旧版识别新增字段。
