## 手机使用

已在 `codex/floating-diagnostic-20261025` 的现有测试安装直接更新并刷新，设置页确认 `1.0.0-test.20261025.diag2`。其他测试分支先在扩展管理切换分支；不要重复安装第二份兰台。

设置 → 关于兰台 → 记录界面诊断。随后“切区 → 闪了／没闪 → 继续切区”，无需等待每次补录完成。结束时点击“停止并导出”，一次保存全部已标记记录。重新记录会替换旧记录，刷新清空内存。

每次标记保留可用的前 30 秒和后 2 秒证据；多个后窗可重叠，滚动缓存淘汰不会抹去已标记窗口。容量最多 32 次／8 MiB 估算预算，达到上限会停录提示导出。关闭、切聊或后台会停止；被中断的后窗会标记不完整。提前停止并导出也可能使最后的后窗不完整。

JSON 为 lantai-ui-transition-v3，observations 按序号标出 flicker/no-flicker、时间、候选切区及独立窗口；多个或未知切区不会强行归因。顶层保留滚动 frames/events。v2 单 capture 字段改为 observations。

不采集正文、标题、输入、HTML、URL、聊天身份或凭据，不自动上传。DOM 记录不能证明手机像素已绘出。标记会复制缓存并可能影响焦点，开销与真实手机交互仍需实测。
