## 本轮变化

工坊收集与长期追踪区分酒馆生成、兰台生成。兰台生成可按条目勾选最近对话、本轮召回记忆、角色资料；最近对话默认6楼，可选2–200楼。复用本轮实际注入的记忆，不新增检索；条目的内容框继续作为生成要求。启用额外资料的条目独立请求，使用最新摘要／追踪／工坊任务API；失败只重试对应条目。旧条目额外资料默认关闭。

## 安装与边界
