## 本轮变化

- 修复追踪来源一致性：普通宿主来源附带语义说话方，成果投影、AI 回合计数及归属清理统一按语义时间线，原生隐藏不再伪装成楼层消失。
- 隐藏正文仍不参与逐回合生成；批总结复用既有回复标识，旧批次首次补标识不误删有效成果，真实删除／swipe 与尾删整批撤销保留原边界。
- 旧逐回合成果如果历史 aiTurn 曾因前方隐藏 AI 楼而偏小，缺少当时隐藏状态，无法可靠自动重编号：仍有效的成果保留存储、暂不参与投影，需要重新生成。生成中途回复标识改变会拒绝采用本轮结果，可重试。

以下行为延续上一版：

- Vertex 批量追踪可空 schema 兼容修复，保留结构化输出与空值含义。

- 全插件只持久保存生成成果、必要楼层／回复归属与旧成果回退记录，不再保存原始／清洗正文、输入记忆副本及重复原料。原聊天与人工设置保留。
- 真实尾删在同一根事务撤销受影响整批成果，并回退大纲、自述、追踪与记忆进度。有真实旧成果则恢复；没有可恢复旧成果的受影响类别回到未生成。无关类别与设置保留。
- 旧数据读取只做内存转换，下次正常根保存成功并确认后迁移；打开页面／渲染不会额外保存。待审核与失败候选保留成果和阶段，继续时读取当前正文。
- 成果中的原文引文保留，不因与聊天文字相同而删除。编辑正文不会自动重生成已有成果。

## 安装与回退

升级前备份聊天、全局设置与扩展，停止生成／总结。在酒馆扩展管理更新后刷新／重启，不同时启用两份兰台，无需清空数据。

重要：旧插件不兼容新成果格式。新版本正常保存后，退回旧插件必须恢复升级前聊天／设置备份，不要仅替换旧代码后继续写入。源码 ZIP 备份不包含你的聊天数据。
