独立诊断分支：本轮增加短录屏与事件日志对齐，不修改闪烁相关布局，不宣称修复。

## 短录屏使用

现有 `codex/floating-diagnostic-20261025` 分支更新并刷新，确认 diag5，无需重复安装。

开始手机录屏，进入设置 → 关于兰台 → 记录界面诊断。浮条自动显示 S 开头的会话号、start 事件及最近两次切区的阶段序号/相对毫秒。只走1—2次原来会闪的切区路线，每次点“闪了／没闪”，最后“停止并导出”。提交同次录屏和JSON，可用会话号匹配。

本轮不需要点击“原裁剪／取消外层裁剪”，默认均未启用。原有对照工具保留，未自行切换布局条件。短录屏避免大量重叠窗口触及原有8 MiB/32次档案上限。

浮条保留requested/shown/ready阶段，不用后阶段替换前阶段。只在阶段事件时更新，没有走动时钟、逐帧DOM更新或插入等待。阶段文本使用独立订阅，不让设置页参与重绘。事件时刻不是呈现时刻，同帧多个阶段不能由浮条分离，不能据此声称已经抓到物理缺绘或因果。

## 记录

JSON schema lantai-ui-transition-v6，videoAlignment保存sessionId、startAnchor及最近两次nav，各最多8条阶段，超出有omittedStages。已标记窗口带sessionId，原连续标记、条件编号与裁剪元数据保留。

可用前30秒＋后2秒窗口可重叠；档案容量满会停录提示导出，已标记窗口不被滚动淘汰。关闭/后台/切聊停止，提前停止的后窗可能不完整。重新记录替换旧记录，刷新清空。仅本机内存，不收正文、标题、输入、HTML、URL或身份，不自动上传。
