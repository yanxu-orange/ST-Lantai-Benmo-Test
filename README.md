## 手机使用

在现有测试版兰台的扩展管理中切换到 `codex/floating-diagnostic-20261025`，更新并刷新页面，设置页确认版本 `1.0.0-test.20261025.diag1`。已有测试仓安装请切分支，不要重复安装第二份兰台。

进入“设置 → 关于兰台”，点击“记录界面诊断”。此后跨分区切换时会保留悬浮按钮“刚才闪了”。看见闪烁后点击它，追加记录2秒后出现“导出记录”。点击导出保存 JSON；“重新记录”会开始新一轮并替换旧记录。关闭或切聊会停止，刷新清空内存记录。

记录目标为最近30秒；帧数、事件数或容量受限时旧记录会提前淘汰。JSON 标明实际保留范围、淘汰量、标记时刻与是否完整完成。标记后发生关闭、切聊或进入后台，会标为未完成而不是伪称完整捕获。

只收集受限界面状态，不收集聊天正文、标题、输入、HTML、URL、聊天身份或凭据，不自动上传。DOM/rAF记录不能证明手机像素已绘出；点击标记也可能影响焦点或键盘，真实手机交互尚待验证。
