## 使用

现有 `codex/floating-diagnostic-20261025` 分支更新并刷新，确认版本 diag3，无需重复安装。

1. 设置 → 关于兰台 → 记录界面诊断。
2. 选择“基准 0 px”（✓为当前选择），按原路线切区，每次点“闪了／没闪”。
3. 选择“缩短 1 px”，走相同路线并标记；再回“基准 0 px”对照。
4. 最后“停止并导出”，保存同一个 JSON。

未选尺寸条件前不改变布局；两组均固定内容容器顶部，仅高度为原可用高度减 0 或 1 CSS px。宿主 +18 不动，背景装饰沿用既有跟随机制。停止/关闭/后台/切聊移除临时样式。基准组是否仍复现需实测，不假定等同未启用；实际尺寸变化须看记录，不能把设置值当成已测到的 1px。
