# 兰台本末 · 手机测试候选

版本：0.1.0-test.20261009.1。本仓库用于 SillyTavern 原生扩展安装与更新，属于测试候选。

## 安装和更新

仓库地址：https://github.com/yanxu-orange/ST-Lantai-Benmo-Test 。已安装本测试仓库时，在扩展管理中更新后刷新或重启酒馆。

先备份扩展目录、SillyTavern 全局设置与聊天资料，停止进行中的生成/总结，不要同时启用两份兰台。新增全局追踪提示词设置字段，旧版不保证兼容；回退须恢复升级前扩展与设置备份，并保留本轮新增资料。

## 本轮变化

- 最新摘要缺省开启；物品追踪、角色追踪继续缺省关闭。已有显式开关值保留，包括上一版保存的关闭值。
- 删除功能管理中本末开关下的两段说明。
- 本末 → 兰台记录 → 物品追踪／角色追踪 → 追踪设置，分别编辑全局内容与追踪要求，支持恢复默认。JSON、记录 ID、类别和自定义字段协议由插件固定提供，模型响应仍经过结构校验。
- 自定义字段要求仍属于单条记录；已开始的任务使用请求开始时捕获的提示词。

角色自述、故事大纲仍为占位。摘要开启后，后续符合条件的生成会按所选 API 产生请求；不自动补历史。普通设置沿用宿主后台保存，已保存不等同于每次磁盘读回确认。
