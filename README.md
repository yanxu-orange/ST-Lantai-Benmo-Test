# 兰台本末 · 手机测试候选

此仓库用于 SillyTavern 扩展安装与更新，不是正式发布版。

## 安装

在酒馆的扩展管理中选择“安装扩展”，粘贴：

https://github.com/yanxu-orange/ST-Lantai-Benmo-Test

安装完成后刷新酒馆，打开兰台本末。之后在扩展管理中更新本扩展并刷新即可获得新候选。

## 当前候选

版本：0.1.0-test.20261003.1。

已接入新建与编辑、列表与时间线、搜索和筛选、多选模式和删除、关键词重建、合并与撤销，以及插件 API 配置、获取模型和测试连接。

本次重点体验：选择一条或多条记忆后重建关键词与简称；点击即开始，关闭插件仍继续运行；重开恢复任务和审核草稿。完成后可按各条原标题编辑新词与简称，旧词默认折叠，点击“保存重建结果”统一保存。返回放弃结果，X 关闭保留结果。

首次使用时，在兰台 API 设置中选择来源并保存；此安装包不包含电脑上的 API 配置或聊天数据。
