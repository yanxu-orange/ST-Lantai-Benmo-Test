## 本轮变化

本轮优化本末重复进入：导航查询只读轻量状态；聊天来源和回复身份未变化时复用已加载记录，仍保留首次加载、来源变更、显式重读及失败保护。

修复自动摘要回执授权时序：关闭期间收到的回复不会因稍后重新开启而被队列补做摘要。手动生成继续使用当前授权。

承接 .4：统一本末顶栏和分段选择控件：删除根顶栏专属高度与间距覆盖；三选一复用公共分段控件和主题选中态，保持原功能和导航。

承接 .3：对白鼬底色和操作文字／图标做清透微调，保留辅助文字、图片、卡片、蓝色选中态和布局。

承接 .2：将孟菲斯共用粉色从 #FF9FF3 调整为 #E9B8CC；黑框、其他颜色和白鼬主题保持。顶栏及分段选择控件的统一调整已在本轮实现。

以下承接 .1：

- 最新摘要缺省开启；物品追踪、角色追踪继续缺省关闭。已有显式开关值保留，包括上一版保存的关闭值。
- 删除功能管理中本末开关下的两段说明。
- 本末 → 兰台记录 → 物品追踪／角色追踪 → 追踪设置，分别编辑全局内容与追踪要求，支持恢复默认。JSON、记录 ID、类别和自定义字段协议由插件固定提供，模型响应仍经过结构校验。
- 自定义字段要求仍属于单条记录；已开始的任务使用请求开始时捕获的提示词。

角色自述、故事大纲仍为占位。摘要开启后，后续符合条件的生成会按所选 API 产生请求；不自动补历史。普通设置沿用宿主后台保存，已保存不等同于每次磁盘读回确认。
