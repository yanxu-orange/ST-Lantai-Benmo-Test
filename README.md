- 预览准备由逐条记忆重复核对整份资料，改为轻量取消检查和发布前完整一致性核对，不删减资料换取速度。

## 安装与回退

已安装时在酒馆扩展管理更新后刷新／重启。升级前备份扩展、全局设置与聊天，停止正在进行的生成／总结，不同时启用两份兰台。无需清空数据。

兼容既有候选、来源回执、叙事进度与暂停任务；退回旧版本应恢复升级前聊天备份，不要仅换旧代码后盲写。生成可能产生 API 费用，停止／取消不保证已发送请求停止计费。手动重叠范围会替换本次所选类别的整组叙事结果，请先确认范围与提示。
