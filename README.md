## 本轮变化

加入默认关闭的 BM25、向量与重排。开启多路后，关键词、BM25、向量及明确日期检索独立产候选，每路5个、去重补位后至多20个，最终普通条数上限不变。纪念日与历史同日另池，剔除最终普通重复后补位；重排异常回退稳定名次融合。向量不能逐段遮罩混合日期查询，只采用可确认的整段日期排除。

任务 API 按文本、向量、重排能力明确分配，旧方案、密钥与选择保留；旧两类总结选择不同需明确统一，不静默换源。向量在本浏览器保存，正式记忆保存确认后后台增量更新；旧库或更换向量模型由用户一键处理，暂停／关闭保留完成部分。向量开关下显示实际状态，就绪不留多余按钮。

## 安装与回退

升级前备份聊天、全局设置与扩展，并停止生成／总结。在酒馆扩展管理更新后刷新／重启，不同时启用两份兰台，无需清空已有成果。

向量缓存不进入聊天备份，清理站点数据或更换设备后需重新处理。旧插件不兼容新成果格式；新版本保存后回退须恢复升级前聊天／设置备份，不能仅换旧代码继续写入。
