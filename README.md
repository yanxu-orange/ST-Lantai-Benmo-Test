## 本轮变化

- 自动摘要失败时记录安全的阶段与错误类别，便于下次失败定位。
- 加强任务来源归属保护，防止过期任务覆盖当前来源的状态。
- 保留 .11 紧凑 UI 与 .10 摘要页面、隐藏同步修复。
- 本轮尚未确认或修复真实环境中自动生成失败的根因。

详见《安装与验收说明.txt》。自动生成可能调用所选 API 并产生费用；停止或取消不保证已发出的 API 请求停止计费。
