## 安装、升级与回退

在 SillyTavern 扩展安装处使用 https://github.com/yanxu-orange/ST-Lantai-Benmo-Test 。已安装本测试仓库时使用扩展更新，然后刷新或重启酒馆。升级前备份扩展、SillyTavern 全局设置和聊天，停止生成和总结，不要同时启用两份兰台。

本末的最新摘要、物品追踪、角色追踪三项全局开关默认关闭。升级后需要在“设置 → 功能管理 → 本末”手动开启；旧聊天启用位不会自动开启全局任务。各聊天资料及其他偏好仍独立。

回退不能只换回旧版安装包：较早版本不保证读取新的全局功能设置、自定义字段和人工摘要标记。应恢复升级前扩展、全局设置及聊天备份，并另存升级后的新增资料；不要用旧版直接改写新格式资料。

## 本轮变化

承接已验收的时间管理、日期召回、轻卡片、工坊移植、设置与功能总控、普通保存响应修复，包含最新摘要、物品追踪、角色追踪、五区导航、自定义字段和来源/swipe保护。

本末三项改为全局开关，功能管理按记忆、时间、本末、工坊四组同层级排列。关闭某项停止该项生成、更新、召回和注入，保留资料；关后重开仍拒绝旧响应，共用请求中其他仍开启项目可保存。全局及当前聊天总开关继续作为总暂停。

恢复摘要设置/查看的紧凑文字入口与分类选中状态，修复宿主高度约束和长页面滚动，使详情、编辑的底部操作可见。角色自述和故事大纲仍为占位，不自动补历史。手动开启后正常运行按所选 API 计费，共用请求不代表免费。

普通“已保存”不是逐次落盘证明，宿主后台保存失败时插件可能无法立即知道。记忆成果、API 凭据及跨域移动目的地继续保留确认和聊天身份保护。
