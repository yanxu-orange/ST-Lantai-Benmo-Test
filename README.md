# 兰台本末 · 手机测试候选

版本：0.1.0-test.20261005.5。本仓库用于 SillyTavern 原生扩展安装与更新，是测试候选，不是正式发布版。

## 安装与更新

在酒馆扩展管理中选择“安装扩展”，粘贴：

https://github.com/yanxu-orange/ST-Lantai-Benmo-Test

已安装本测试扩展时，在扩展管理中更新本扩展，然后刷新酒馆。更新前请备份重要聊天和设置；若正在生成，请先完成并保存，再更新和刷新。无需导入酒馆助手脚本，也不要同时启用多份兰台本末。

## 当前完整候选

- 默认孟菲斯；在底部“设置”中的外观分组，可切换孟菲斯与雪山白鼬。白鼬提供雪山头图、浅色工作区与独立外观保存，不改变业务数据、生成与召回规则
- 保留记忆新建/编辑、列表/时间线、搜索/筛选、多选/删除、关键词重建、合并与撤销，以及事件启用控制
- 包含完整事件生产、入库前审核、分批总结、重新生成、停止/继续与失败恢复，以及提示词、词库和清洗设置
- 包含已移植的古法首次/追加生成、审核采用、历史版本、自动/再生与恢复流程；未点名场景仍需实机验收
- 保留正式事件召回、独立召回测试与实际发送监控、原文替代，以及插件 API 配置、获取模型和测试连接

古法手动新建/前置剧情、最新摘要、日期关联召回与正式 PC 布局仍在后续范围。首次使用请自行保存 API 来源与配置；安装包不包含个人凭证、聊天或用户设置。

## 本轮修复

- 总结页长内容保留自然高度，修复白鼬预览卡片裁剪导致无法滚动
- 主题资源准备后立即预览，后台保存；不确定或失败时恢复已确认外观并提示重新读取
- 清洗快捷添加立即显示待保存条目，确认后合入列表；不确定时保留恢复提示，避免重复提交
