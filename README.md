## 本轮变化

- 摘要手动编辑、历史补录与可取消批次；保留已有摘要和原有自动规则。
- 每聊天物品／NPC 独立名称名单和按记录 ID 暂停。停止自动新增、更新、追踪上下文与注入，保留历史、已有记录和人工编辑；恢复不回补。
- 名称规范化精确匹配与已知别名证据，不能保证识别未知别名，也不会泛化成所有同类物品。
- 外部更新、切聊、队列与暂停恢复竞态守卫；保存开始清旧注入，在途结果不得回灌。
- 保留 .8 的摘要／工坊自动合批、展示顺序、正文编辑后摘要保留及事件／古法批次修复；本轮无 UI 美化。

详见《安装与验收说明.txt》。自动生成可能调用所选 API 并产生费用；停止或取消不保证已发出的 API 请求停止计费。
