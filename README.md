# 兰台本末 · 每回合日程与批量追踪测试版 0.1.0-test.20261013.2

本版接续已发布的 0.1.0-test.20261013.1，合并此前未发布的总结体验修复、批量同步追踪和信息追踪提示词调整。开发源码：https://github.com/yanxu-orange/Lantai-Benmo-dev 。安装仓库：https://github.com/yanxu-orange/ST-Lantai-Benmo-Test 。

## 本轮变化

- 每回合日程追踪默认关闭，可选择日常安排、纪念日候选并编辑提取要求。与最新摘要同时开启时共用本轮剧情和一次联合请求；关闭最新摘要也可独立运行。时间管理总开关关闭时不自动提取或提醒，已有候选仍可查看。
- 日期和安排明确的日程自动进入日历，默认开启单项提醒，并遵循全局提醒开关和提前设置。不明确的安排、纪念日先进入现有时间管理页的候选区；启用前不进入月历、提醒或纪念日召回。保留人工改动和手动关闭的提醒设置。
- 可处理跨轮改期、取消、完成和按故事日期判断的单次过期；周年事项不会因一次过期永久停用。本版不增加无日期待办或周／月循环。
- 楼尾显示本轮新增、更新和候选数量，可跳转原管理页。日程失败可单独重试；重新生成摘要只处理摘要。批量事件总结已有的纪念日候选确定性补录到同一入口，不额外请求模型，不因重复打开而复活已采用或忽略的候选。
- 批量事件总结可同步角色、物品追踪，默认关闭，三种总结模式均复用原始剧情首轮请求。新增独立“信息追踪提示词”编辑框，包含纪念日候选、角色追踪、物品追踪三部分，与每回合追踪提示词独立。旧自定义内容和空白覆盖保留。
- 修复事件总结的隐藏剧情来源、无进度时“尚未总结”提示、审核输入焦点和滚动、连续删除及未确认保存后的重新读取。保留 .1 的最新摘要发送正文修复，以及既有主题、字体和提示词体系。

## 安装

已安装时在酒馆扩展管理更新后刷新／重启。升级前备份扩展、全局设置与聊天，停止正在进行的生成／总结，不同时启用两份兰台。无需清空数据。新增批量追踪和每回合日程追踪均需自行开启。

日程自动更新会校验来源和人工改动，遇到冲突会保留现有资料；批量追踪遇到范围重叠等冲突时也会保留原追踪，事件总结仍可采用。请按界面提示重新读取或处理候选，不要直接清空资料。

## 验证与体验边界

最终冻结候选验证通过：448 份文件语法检查、187 份源码／514 条静态依赖、完整 3091/3091 自动测试，0 失败、取消或跳过，测试自然结束且退出码为 0，构建通过。UI、数据域和运行时三路独立审查均无剩余已知阻断；运行时另通过 12 个独立反例检查。

本轮未调用真实模型 API，自动测试使用虚构宿主和模型输入输出。真实 SillyTavern、手机软键盘和模型提取质量仍待实机验收；自动测试或 DOM 测试不等于这些项目已通过。

更新后建议依次体验：

1. 先保持新开关关闭，确认原摘要、总结、主题和自定义提示词仍正常。
2. 开启日程追踪，检查明确日程的日期与提醒；在管理页编辑、启用或忽略不确定安排及纪念日候选。
3. 关闭最新摘要后检查日程独立运行；同时开启时检查楼尾结果及单独重试。
4. 检查改期、人工编辑保护、关闭提醒后的后续更新，以及批量总结纪念日补录是否重复。
5. 开启批量角色／物品追踪，确认三类信息追踪要求可编辑，与每回合提示词分别保存。

生成可能产生 API 费用；停止／取消不保证已发出的请求停止计费。回退前备份并保留新资料，本版新增候选与来源回执存储字段；退回旧版应恢复升级前的聊天备份，不要清空聊天或仅换旧代码后盲写。

## 安装树范围

安装树仅包含正式插件模块、固定供应组件、既有主题／字体资产、manifest 和安装说明，不包含开发预览、fake adapter、私有聊天、作者附件、日志、备份或私密 QA。字体许可证随资产保留。BUILD-HASHES.json 覆盖除自身外的全部安装文件。

既有楼尾 HTML／助手渲染的实机边界保持：静态 HTML/CSS 与含前端脚本的渲染路径不同，真实 iframe 释放、输入桥、外部媒体及移动端长正则性能仍需实机核对；运行中修改助手渲染开关／深度后需刷新页面。
