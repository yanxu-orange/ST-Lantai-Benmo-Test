## 本轮变化

- 按确认的三份提示词定稿：单独自述代入角色，单独大纲采用故事编辑，联合以创作助理先后代入编辑与角色并统一输出。保留具体要求与爱丽丝示例；姓名发送前替换，空栏目省略，必要 ID 仅在返回规则中出现。
- 预览与请求消息同源。旧精确默认提示词在组装时采用新默认，不写回设置；用户自定义文本保留，仅替换角色名变量。
- 记忆／原文改为单选，联合共用一个来源。手动沿入口选择；自动两项都选原文才采用原文，否则采用记忆，古法固定原文。旧双选／双空只读解释为记忆。
- 保留现有读取、串行保存、失败恢复与来源核对，不新增加载层。离线预览模拟器已适配新提示词并保留旧条目。
