记录与导出

设置页底部“关于兰台”区域增加“导出生成诊断”按钮。记录最多 300 条，仅保存在当前页面内存，刷新会清空，不持久化、不自动上传；按钮将 JSON 下载到本地。

记录固定操作名称、时间和顺序、有限按钮与键盘分类、酒馆生成开始类型及结束／停止事件，以及兰台文本 API 请求的 route/group、起止和状态。不会记录字符、输入值、正文、原始参数、异常原文、URL、模型名称、密钥或聊天／记忆 ID。

操作记录只表示观察到操作，不代表保存成功；请求开始只表示进入执行尝试，不保证网络成功；结束／停止事件不强行关联到某个请求。记录本身用于核对先后关系，不自动推断责任或根因。
